1. Introduction

This manual contains procedures for maintenance of Reactor Room 7-G systems. The TECHNICIAN operates the maintenance terminal while HOTLINE SUPPORT provides guidance using this manual.

⚠ IMPORTANT: The Technician CANNOT see this manual. Hotline Support must communicate all necessary information verbally.

Edgework

Many procedures reference "edgework" - information displayed on the Reactor Status panel:

  • Serial Number: 6-character alphanumeric code (e.g., AB3CD5)
  • Batteries: Number of backup batteries (0-4)
  • Parallel Port: YES or NO
  • Indicators: Labeled lights (CAR, FRK, SIG, BOB, etc.) - lit or unlit

2. Coolant Bypass Valves

The module displays 3-6 colored pipes. Close ONE valve to restore nominal flow.

⚠ Closing the wrong valve causes catastrophic backpressure!

Valve Colors

R = Red B = Blue Y = Yellow
W = White K = Black

3 Valves

  • If no RED valves: Close valve 2
  • Otherwise, if valve 3 is WHITE: Close valve 3
  • Otherwise, if more than one BLUE valve: Close the last BLUE valve
  • Otherwise: Close valve 3

4 Valves

  • If more than one RED valve AND serial number ends in ODD digit: Close the last RED valve
  • Otherwise, if valve 4 is YELLOW and no RED valves: Close valve 1
  • Otherwise, if exactly one BLUE valve: Close valve 1
  • Otherwise, if more than one YELLOW valve: Close valve 4
  • Otherwise: Close valve 2

5 Valves

  • If valve 5 is BLACK AND serial number ends in ODD digit: Close valve 4
  • Otherwise, if exactly one RED valve AND more than one YELLOW valve: Close valve 1
  • Otherwise, if no BLACK valves: Close valve 2
  • Otherwise: Close valve 1

6 Valves

  • If no YELLOW valves AND serial number ends in ODD digit: Close valve 3
  • Otherwise, if exactly one YELLOW valve AND more than one WHITE valve: Close valve 4
  • Otherwise, if no RED valves: Close the last valve
  • Otherwise: Close valve 4

3. Emergency Override

A large button with a colored label. Either PRESS (tap) or HOLD the button.

Decision Tree

  1. If the button is BLUE and says "ABORT": HOLD
  2. If there are more than 1 battery and the button says "DETONATE": PRESS
  3. If the button is WHITE and there is a lit CAR indicator: HOLD
  4. If there are more than 2 batteries and there is a lit FRK indicator: PRESS
  5. If the button is YELLOW: HOLD
  6. If the button is RED and says "HOLD": PRESS
  7. Otherwise: HOLD

If Holding

When you hold the button, a colored strip will appear. Release when the countdown timer shows the correct digit:

Strip ColorRelease When Timer Contains
Blue4
Yellow5
Any other color1

6. Pressure Locks

Navigate from the player marker (■) to the target (▲) without hitting invisible walls.

⚠ Hitting a wall causes a strike!

Reading Coordinates

The grid displays column numbers (0-5) across the top and row numbers (0-5) down the left side.

Coordinates are given as (column, row) — for example, (2,3) means column 2, row 3.

Identifying the Maze

Two cyan reference markers (◙) appear on the grid. Find the maze below with markers in matching positions, then guide the Technician around the walls.

⚠ Walls are INVISIBLE to the Technician! You must guide them step by step.

Appendix A: Edgework Reference

Serial Number

A 6-character code displayed on the Reactor Status panel (e.g., AB3CD5).

  • Contains Vowel: Check if A, E, I, O, or U appears anywhere
  • Last Digit Odd: Check if the final digit is 1, 3, 5, 7, or 9
  • Last Digit Even: Check if the final digit is 0, 2, 4, 6, or 8

Indicators

Labeled lights that may be LIT (on) or UNLIT (off).

Common labels: CAR, FRK, SIG, BOB, CLR, IND, MSA, NSA

Batteries

Count of backup batteries (0-4).

Parallel Port

Whether a parallel port connector is present (YES/NO).
